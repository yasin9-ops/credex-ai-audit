# AI Spend Audit

AI Spend Audit is a lightweight SaaS-style auditing tool that helps startups identify unnecessary AI subscription spending and discover optimization opportunities.

The app analyzes AI tooling costs, recommends more efficient plans, estimates potential savings, and generates an AI-powered summary.

## Features

- AI tool spend audit form
- Audit recommendation engine
- Monthly + annual savings estimation
- AI-generated audit summary
- Responsive modern UI
- Local storage persistence
- Deployed Next.js application

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- OpenAI API
- Vercel
